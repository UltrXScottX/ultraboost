# UltraBoost
# A lightweight Fabric performance mod for Minecraft 1.21.6

## Features
- Smart entity culling
- Particle reduction
- Optional simulation distance tuning
- Fast fog and render scale options
- Light update reduction
- Configurable entity throttling
- Cloth Config + Mod Menu support

## Build
```bash
gradle build
```

## Install
1. Put the generated JAR in your Fabric mods folder.
2. Ensure Fabric Loader 0.16+ and Fabric API are installed.
3. Launch Minecraft 1.21.6 with Fabric.

## Controls
- Right Shift: Open UltraBoost config
